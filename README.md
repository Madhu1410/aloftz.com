# ALOFTZ Marketing Pvt. Ltd. — Website Package

## Overview
A complete multi-page website for ALOFTZ Marketing Pvt. Ltd., built as a high-end single HTML file with all CSS and JavaScript embedded.

## Pages Included
1. **Home** — Hero, stats, services overview, process, work teaser, testimonials, CTA
2. **About** — Brand story, values, team cards, milestones
3. **Services** — Glass tabs per service, pricing table, FAQ accordion
4. **Work/Portfolio** — Filterable project gallery
5. **Blog** — Tabbed blog grid by category
6. **Contact** — Split layout with contact info and form

## Brand Palette Used
- Abyss: #0A1F22 (Main Background)
- Deep Teal: #0D5C63 (Primary)
- Ocean: #107A84 (Secondary)
- Horizon: #1AB564 (Accent)
- Mist: #D6F0F3 (Light Base)
- Gold: #C9A84C (Premium CTA)
- Slate: #6B8C90 (Body Text)
- Off White: #F4FAFB (Surface)

## Tech Stack
- Pure HTML5 / CSS3 / Vanilla JavaScript
- Google Fonts: Syne, DM Sans, Space Mono
- No external dependencies (except Google Fonts CDN)
- Single file, zero build process required

## How to Use
1. Open `index.html` in any modern browser
2. To deploy: upload `index.html` to any web host, GitHub Pages, Netlify, or Vercel

## Team Data
All team member data (Anoushka Kundu, Madhushree Banik, Pumpkin Halder, Loknath Mondal, Rohit, Sourav, Patrick) is stored in the JavaScript DATA object at the bottom of index.html and can be easily updated.

## Customisation
All content is in the `DATA` object inside the `<script>` tag. Update:
- `DATA.company` — company info, phone, email, address
- `DATA.team` — team member names, roles, bios
- `DATA.services` — service names, descriptions, features
- `DATA.pricing` — pricing tiers and amounts
- `DATA.testimonials` — client testimonials
